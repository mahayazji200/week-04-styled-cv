المهمة 1: نسّق سيرتك الذاتية

طبّق تنسيقات CSS على سيرة ذاتية بسيطة مكتوبة بلغة HTML. أكمل جميع المهام (TODO) الموجودة في قسم <style> في أعلى الملف.

TODO 1: تنسيق الصفحة والخط

اجعل الخط 'Inter', sans-serif، وأضف لون خلفية داكنًا، واختر لونًا فاتحًا للنص في الصفحة كلها.

الخصائص: font-family, background-color, color, line-height

TODO 2: رأس بخلفية متدرّجة

نسّق القسم .cv-header بخلفية متدرّجة (Gradient)، ونص في المنتصف، وحشوة (padding) واسعة.

الخصائص: background: linear-gradient(135deg, #1a1a2e, #16213e), text-align: center, padding, border-radius

TODO 3: المهارات على شكل وسوم

حوّل قائمة المهارات إلى وسوم ملوّنة، بحيث تظهر كل مهارة كقرص صغير ملوّن بحواف دائرية.

الخصائص: list-style: none, display: inline-block, background, padding: 5px 15px, border-radius: 20px, margin: 5px

TODO 4: جدول منسّق

نسّق جدول المؤهلات الدراسية بإضافة حدود، وخلفية لصف العناوين، وألوان متناوبة للصفوف.

الخصائص: border-collapse: collapse, border, :nth-child(even), padding

TODO 5: تنسيق الروابط

نسّق جميع الروابط باللون الأخضر ومن غير خط سفلي، وأضف تأثيرًا عند مرور الفأرة (hover).

الخصائص: color: #4caf50, text-decoration: none, :hover

TODO 6: ظل الحاوية

أضف ظلًا (box-shadow) إلى .cv-container لتبدو كبطاقة عائمة فوق الصفحة.

الخاصية: box-shadow: 0 5px 30px rgba(0,0,0,0.3)

TODO 7: صورة دائرية

اجعل الصورة الشخصية دائرية مع إطار أخضر وظل.

الخصائص: border-radius: 50%, border: 3px solid #4caf50, box-shadow, width: 150px
